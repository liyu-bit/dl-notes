#   Python 3.12.15 · conda 环境名 dl ·驱动 571.96 · PyTorch 2.13.0+cu126
#   GPU: RTX 4060 Laptop (sm_8.9, 8.0 GB)

# 安装（推荐先装驱动，再装 PyTorch）：
#   pip install -r requirements-gpu.txt --index-url https://download.pytorch.org/whl/cu126
#
# 装完务必运行 python scripts/check_env.py 确认 torch.cuda.is_available() 为 True。
#
# 若 torch.cuda.is_available() 为 False，按顺序排查：
#   1. nvidia-smi 看驱动版本，驱动版本比 CUDA 版本更重要
#   2. python -c "import torch; print(torch.version.cuda, torch.cuda.is_available())"
#   3. 确认没混装 conda 与 pip 两套 torch：pip list | grep -i torch

# 注意：torch 的 cu 版本必须 ≤ 驱动支持的 CUDA 上限。本机驱动支持到 12.8，
#      因此 cu124 / cu126 / cu128 都可以，cu126 是已实测的组合。
